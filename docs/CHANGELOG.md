# Changelog

## 2026-11-01 — Public GitHub release

- Published all three signed APKs in one repository
- Added professional README with download table, checksums, install guide
- Added per-app pages with confirmed features, packages, and Android requirements
- Added INSTALL, CHECKSUMS, RELEASES docs

## v1.2.0 — 3D File Viewer (`com.amintoor.viewer3d`)

- Recent-files library with search + favorites
- GLB/glTF support alongside STL/OBJ/PLY/3MF
- Position slider, share, settings
- Targets Android 15 (min 8.0)

## v1.1.0 — AminToor Converter (`com.amintoor.converter`)

- PDF merge/split, PPTX→PDF, images→PDF
- Edited-PDF saving, page navigation
- Targets Android 15 (min 8.0)

## v1.0 — AminToor To-Do (`com.amintoortodo.app`)

- Task list with notes, due dates, search & filters
- On-device storage
- Supports Android 6.0+, targets Android 12L
