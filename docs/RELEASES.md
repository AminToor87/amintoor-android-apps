# Releases

## v1.2.0 — 3D File Viewer (latest)

- Open & explore 3D models: STL, OBJ, PLY, 3MF, GLB, glTF (+ MTL/BIN/textures)
- Recent-files library, Search, See all, Favorites
- Touch viewer: drag to rotate, model size chip
- Model position slider (Up / Down / Centered)
- Share 3D model
- Package `com.amintoor.viewer3d`, versionCode 3, Android 8.0+, target Android 15

Asset: `apps/3d-file-viewer/AminToor-3D-File-Viewer-v1.2.apk` (1.9 MB)
